Agent 学习路线：从第一个循环到可靠评测

按顺序学习；链接优先指向课程发布方、框架维护者和基准官方页面。

1. 先判断要不要 Agent：Building effective agents · Anthropic
先区分固定 workflow 与由模型决定下一步的 Agent，再学提示词链、路由、并行、编排器-工作者和评估器-优化器。练习：同一个任务画两种方案，并说明为什么选最简单够用的一种。
2. 做第一个工具 Agent：AI Agents Course · Hugging Face
从 Think → Act → Observe 学工具调用与 Agent loop，用 smolagents 构建并发布 Alfred。适合初学者；包含练习和单元测验。
3. 学会状态、恢复与人工介入：AI Agents in LangGraph · DeepLearning.AI / LangChain
约 1 小时 47 分，先手写 Agent 再用 LangGraph 重建，覆盖持久化、streaming、人类介入。练习：做一个中断后可恢复、关键动作需审批的研究流程。
4. 横向比较官方开发栈 · OpenAI Agents SDK · Google ADK · Microsoft Agent Framework
对照 tools、handoffs、sessions、workflows、guardrails 与 tracing；先用各自官方 quickstart 做同一个小任务，不要只凭教程截图选框架。
5. 用外部基准验证，而不是让 Agent 自己打分 · SWE-bench · OSWorld · WebArena · τ-bench · Terminal-Bench
按任务选编码、桌面、浏览器、工具交互或终端基准。先跑单个样例并记录环境、模型、工具、完整轨迹、成功率、重试、耗时和成本；榜单只在配置可比时参考。

项目练习：① 最小工具 Agent（schema、超时、步数上限）；② 可恢复的研究 Agent（搜索、引用、草稿、事实检查）；③ 小型编码 Agent（外部测试验收）。先定位单 Agent 的具体失败，再决定是否需要多 Agent。

科研前沿：论文与基准（2025–2026）

来自高校与研究机构、会改变 Agent 系统设计或评测结论的工作；点标题看原文。

Agent Skills for Large Language Models · 多机构联合综述
Skills 化是 2026 年 Agent 架构主线：SKILL.md 规范、渐进式加载、与 MCP 的互补关系；并首次系统讨论技能安全——26.1% 的社区技能存在漏洞。
Agentic Tool Use in Large Language Models · 哈工大（深圳）· TikTok
把工具使用研究整理成「提示 → 监督工具学习 → RL 工具策略」三段史，附覆盖 BFCL、SWE-bench、OSWorld、τ-bench 的三级基准地图。
A Survey on Evaluation of LLM-based Agents · 希伯来大学 · IBM Research · 耶鲁（ACL 2026 Findings）
评测全景：从单轮分数到轨迹级评估，附 Langfuse / Arize / LangSmith 等评测框架的能力对照表。
From LLM Reasoning to Autonomous AI Agents · 多机构联合综述
60+ 基准 × 8 个能力域的分类学：同一模型 SWE-bench 87% 而 GAIA 44%，单看一个分数选 Agent 会踩坑。
Recognize Your Orchestrator：调度中枢才是瓶颈 · 南京大学 NLP · 计算机软件新技术全国重点实验室（ICML 2026）
对 Deep Research / Agent Coder / GUI Browser / Agentic RAG 做失败归因：Orchestrator 平均背 63.8% 的失败责任，执行器只占 32.4%。还发现「推理陷阱」——越想得长，留给观察外部信号的空间越少。
Context Engineering：From Prompts to Corporate Multi-Agent Architecture · arXiv 2603.09619（单作者预印本，2026-03）
把上下文当作 Agent 的操作系统，给出五条质量标准：相关性、充分性、隔离性、经济性、可追溯；再往上叠 intent / specification 两层，构成四层成熟度金字塔。作者自承是框架而非实证，当词表用比当结论用更稳。
SETA：为终端 Agent 规模化造环境 · CAMEL-AI · 帝国理工 · UCL · 牛津 · KAUST · 斯坦福 · SambaNova（arXiv 2607.10891）
SETA-Synth + SETA-Evol 两条流水线共享同一套验证机制，产出 4,500+ 可验证终端环境，是当前最大的开源终端 RL 环境集；Qwen3-8B 用 GRPO 训后在 Terminal-Bench 2.0 拿到 12%，同规模 RL 模型里最高。
Environment Evolution：环境该随模型一起变难 · 腾讯混元（arXiv 2609.04128）
指出从零合成的环境对前沿模型已经太简单、给不出学习信号；改为 off-policy 逐代抬高难度，Qwen3.6-27B/35B-A3B 在 Terminal-Bench 2.1 上分别 +14.4 和 +18.0 个百分点。
BIRD-RL：在有状态的数据环境里做 Agentic RL · arXiv 2610.29426
工具中心的环境套不上 SQL 调试这类有状态任务：一条轨迹一个库太贵，共库又互相污染。用轨迹作用域的持久执行设施复用数据库副本，把空间效率提到 12.8 倍，7B/14B 模型成功率 44.4% / 48.0%。
ASCon：多智能体故障归因的统一表征 · arXiv 2608.10646
「谁错了、哪一步错的、错在哪类模式」三件事其实共享同一批轨迹证据，此前却各训一个模型。方向感知图注意力统一建模后，故障 Agent 识别 +5.83、故障步骤识别 +10.63、故障模式 Macro-F1 +14.73。
C-World：计算机使用 Agent 环境创建器 · UC San Diego（ACL 2026）
按需创建 Agent 训练/评测环境：5,571 个工具、204 个真实应用、可注入故障；1,170 条轨迹微调超过 119k 样本基线。
AGENCYBENCH：百万 Token 真实场景自主 Agent 基准 · 上海交大 · GAIR · 上海创新研究院（ACL 2026）
长时程真实任务：单任务平均 100 万 token、90 次工具调用、数小时执行；闭源模型平均 48.4%，开源 32.1%。
AgentGym2：去理想化的真实世界 Agent 评测 · ACL 2026
刻意引入噪声、欠规格指令和工具发现环节；15 个前沿模型全部表现挣扎。
EvoClaw：持续软件演化 Agent 评测 · USC · Princeton（ICML 2026）
把开源仓库的 commit 历史重建为可执行的里程碑 DAG：独立任务 >80%，持续演化场景最高仅 38%。
Agent Planning Benchmark（APB） · arXiv 2606.04874
把规划能力单独拆出来测，含坏工具与不可解任务：会生成看起来合理的计划，不代表能识别计划不可执行。
Agentic Abstention：Agent 知道何时该停下吗 · Hugging Face Daily Papers 收录（2026-06）
把「继续行动还是停止/弃权」建模为序贯决策问题——长程 Agent 的失败往往不是某一步错了，而是该停不停。
ToolVerse：Agentic RL 环境 · arXiv 2607.15660
把 Agentic RL 环境扩到近 400 个真实 MCP 环境、约 4,500 个工具：训练瓶颈正从算法转向环境与 verifier。
Memora：遗忘感知记忆 · arXiv 2604.20006
记忆的一等问题从「能不能记住」变成「何时该遗忘」：FAMA 指标显式惩罚使用过期记忆，多种 memory agent 中招。
